# Prototype Godot

1. Installer Godot 4.x sur Windows.
2. Cloner le dépôt : `git clone https://github.com/darlyblake/LIBREVILLE-STORIES.git`.
3. Ouvrir le dossier du dépôt dans Godot via **Importer** / **Import**.
4. Lancer le projet avec F6 ou F5.

Contrôles : ZQSD/WASD ou flèches pour se déplacer, Espace pour sauter, souris pour orienter la caméra. Échap libère la souris ; cliquer dans la fenêtre la recapture.

Cette scène est un terrain de test technique, pas encore la carte de Libreville.
